Bot ativo para servidores Discord

Xenoryx SuperAgent crie, mande e teste.

SuperAgent é um bot autônomo para Discord que executa tarefas completas por conta própria — escreve e roda código, pesquisa e navega na web, lê e gera arquivos, e interage com o GitHub — usando modelos de linguagem gratuitos via OpenRouter.

Convidar para o servidor Ver recursos

Integração oficial

Conectado ao Discord por meio da API e do sistema de autorização OAuth2.

Eventos e comandos

Em vez de responder apenas com texto, ele recebe uma tarefa em linguagem natural e a executa de ponta a ponta.

Permissões controladas

As permissões dependem do que o bot realmente precisa para funcionar.

Experiência visual

Fundo interativo em Three.js para dar presença sem exagerar nas promessas.

O que este bot faz

  • Interage com servidores via API oficial do Discord.
  • O agente tem acesso a um ambiente de execução isolado onde roda código e comandos de shell de verdade
  • Também consegue pesquisar na web e controlar um navegador real na nuvem para acessar sites que exigem interação, login ou JavaScript. Arquivos gerados durante uma tarefa — sejam scripts, planilhas, imagens ou documentos — são entregues como anexos reais no Discord, prontos para uso.
  • Cada usuário pode conectar sua própria conta do GitHub por OAuth, permitindo que o agente leia repositórios, crie commits, abra branches e Pull Requests.
